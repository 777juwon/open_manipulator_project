# 같은 그린 저장소에서 에피소드 10~29 제외

대상은 `juwon777/omx_green_dualcam_20261116_112902`로 고정한다. 현재 30개인 경우만
처리하며, 0~9번을 보존해 같은 주소에 10개를 남긴다. 다른 원본 및 학습 중인 별도
100개 선택 사본에는 쓰지 않는다. 로컬 원본 30개는 이름을 바꿔 백업한다.

실행 위치: Docker 내부 터미널. 같은 그린 원본의 Record·편집·업로드는 모두 종료한다.

미리보기만 수행:

```bash
/opt/lerobot_venv/bin/python -I /root/ros2_ws/src/open_manipulator/tools/remove_green_10_29.py
```

실제 수행:

```bash
/opt/lerobot_venv/bin/python -I /root/ros2_ws/src/open_manipulator/tools/remove_green_10_29.py --apply
```

원본과 별도 사본을 만들고 남길 0~9번의 관절·Action·시간표와 영상 구조를 검사한다.
Hub와 로컬 메타데이터가 다르면 중단한다. 로컬 원본은 `_backup_before_delete_시각`으로
보존하고 정리한 10개 사본을 기존 경로로 옮긴다. 같은 Hub main에 새 데이터와 오래된
조각 제거를 한 커밋으로 적용하며, 검사 후 다른 커밋이 생기면 parent_commit 검사로 실패한다.
마지막에 v3.0 태그를 새 커밋으로 갱신한다. 저장소 공개 여부는 변경하지 않는다.

삭제는 현재 main에서의 제외이며 과거 Hub 커밋과 로컬 백업에는 데이터가 남는다.
시간 로그는 수정하지 않는다. 원격 갱신 실패 시 로컬은 10개, Hub는 기존 또는 갱신 상태일
수 있으므로 출력과 Hub 커밋을 확인하고 무작정 재실행하지 않는다. 태그 갱신만 실패하면
main은 이미 갱신됐을 수 있다. 로컬 파일 전체 잠금 기능은 없으므로 동시 편집하지 않는다.

명령은 사용자가 직접 실행한다. 장치와 원격 변경 없는 회귀 테스트만 수행했으며 실제
삭제·업로드 동작은 실행하지 않았다.
